# CPU-X

Современная программа для просмотра информации о системе на Windows.  
Написана на чистом C с использованием Win32 API и WMI. Не требует прав администратора.

> Рекомендуется Windows 11 для наилучшего визуального восприятия (Mica/Tabbed эффект, тёмная тема).

## Возможности

- **Процессор**: название, сокет, степпинг, количество ядер и потоков, базовые частоты, кэши L2/L3, поддерживаемые инструкции, разрядность
- **Материнская плата**: модель, производитель, версия BIOS
- **Оперативная память**: тип, объём, частота
- **Видеокарта**: название и объём видеопамяти

Интерфейс выполнен в современном тёмном стиле Windows 11 с поддержкой эффектов DWM.

## Сборка

### Требования
- Visual Studio 2019 / 2022
- Windows SDK

### Как собрать
1. Откройте файл `CPU-X.sln` в Visual Studio
2. Выберите конфигурацию **Release** и платформу **x64** (или x86)
3. Нажмите **Build → Build Solution**

Готовый `.exe` появится в папке `x64/Release` (или `Release`).
